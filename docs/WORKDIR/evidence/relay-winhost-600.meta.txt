=== the exit code, stated plainly ===
EXIT=-1073741819 = 0xC0000005, an access violation. This is the KNOWN pre-existing crash at the
END of a headless run, already recorded as still-open: it happens after every frame and every CRC
has been written, which is why the CRC stream is the verdict and the exit code is not gated on.
Not a new fault and not fixed here.

=== two invocation traps, both silent ===
generalszh.exe is a WINDOWS-subsystem binary, so PowerShell does not wait for it - only
Start-Process -Wait blocks. CNC_GENERALS_ZH_PATH is mandatory; without it the engine finds no data
and hangs having written ~1239 bytes of stderr.
Additionally, the map argument contains BOTH spaces and backslashes and does not survive
bash -> ssh -> PowerShell quoting: it arrives split, and PowerShell reports "A positional parameter
cannot be found that accepts argument 'maps\alpine'". Run it from a .ps1 on the box rather than
building the command line through ssh.
