Why it can never exit - openal_soft al/error.cpp, the no-current-context path:
    static const ALenum deferror{get_value("__ALSOFT_DEFAULT_ERROR", "default-error")};
    WARN("Querying error state on null context (implicitly {:#04x})", as_unsigned(deferror));
    return deferror;                      // get_value() defaults to AL_INVALID_OPERATION
alGetError() therefore returns AL_INVALID_OPERATION on EVERY call and never AL_NO_ERROR.
The per-call WARN is why the stack is usually inside fmt - that is where the CPU went.
